训练流程（当前版本）

服务器初始化全局模型和语义锚点 anchor_bank（每类一个向量）。
每轮通信开始，服务器把当前 anchor_bank 下发给所有客户端。
有标注客户端本地训练：
正常分类损失（含双视图增强）。
计算本地类别原型（特征均值）并做锚点正则（原型贴近对应锚点）。
做锚点分类器校准（锚点输入分类头应输出正确类别）。
回传本地模型参数 + 原型统计量（proto_sum/proto_count）。
无标注客户端本地训练：
一致性损失（student vs EMA teacher）照常保留。
用“模型logit + 锚点相似度”构造伪标签并做伪监督。
做特征到对应锚点的对齐损失 + 锚点分类器校准损失。
回传本地模型参数。
服务器聚合：
先用 FedAvg 聚合所有客户端模型参数得到新全局模型。
再用有标注客户端上传的原型统计通过 EMA 更新
